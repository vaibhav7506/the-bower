# Image and content handoff

`menu.json` is the single source of truth for the menu. Phase 5 templates will iterate over its `courses` and `items`; dishes should not be added as hard-coded HTML.

The three supplied source photos and their approved Phase 1 derivatives are stored with stable filenames:

- `img/hero-source.png` — Photo 1, the brass-fixture / bottle-green interior.
- `img/hero-graded.png` — the gently warmed, contrast-balanced hero derivative.
- `img/pendant-source.png` — Photo 2.
- `img/texture-pendant.png` — the wide pendant-light detail for the moments strip.
- `img/carpet-source.png` — Photo 3.
- `img/texture-carpet.png` — the wide carpet-pattern detail for the moments strip.

Photos 2 and 3 must never appear as full room imagery. Their texture derivatives are used only as abstract mood accents.
